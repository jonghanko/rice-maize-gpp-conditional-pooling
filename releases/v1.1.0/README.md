# Frozen verification data and code 1.1.0

Use the versioned [GitHub release](https://github.com/jonghanko/rice-maize-gpp-conditional-pooling/releases/tag/v1.1.0) and its three attached assets. The build was committed before release publication; the actual release page, immutable badge/API status and downloaded asset hashes establish current access.

- `rice-maize-gpp-conditional-pooling-v1.1.0.zip`: complete verification projection,42files.
- `PACKAGE_MANIFEST.json`:41member hashes; the manifest's own hash is in the sidecar.
- `SHA256SUMS.txt`: verification ZIP and manifest SHA-256 values.

The automatically generated source archive contains the aggregate software and release documentation. It is not the42-file verification-data ZIP. Download and extract the attached ZIP before running `python code/verify_package.py --hashes-only`. The code copies in this directory are for source inspection; do not run them against this incomplete source-tree directory.

The projection preserves reference GPP and lineage, stored paired predictions, validation-fold membership, case/companion catalogues, denominator definitions and observation-reuse crosswalks. Prespecified Ridge LOSO C−S, planned contrasts, secondary combinations and post hoc claims retain their roles. It supports the conditional Korean-rice/US-maize GPP comparison; it is not a four-crop GPP/ET, agent-value, regional-transfer or full model-training reproduction.
