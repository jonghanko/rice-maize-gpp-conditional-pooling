# Rice maize GPP conditional pooling

The repository provides two complementary versioned outputs for the conditional Korean-rice/US-maize GPP comparison.

| Version | Scope | Access |
|---|---|---|
|1.1.0|Frozen reference/prediction/fold and observation-reuse verification projection|[Release and three attached assets](https://github.com/jonghanko/rice-maize-gpp-conditional-pooling/releases/tag/v1.1.0)|
|1.0.0|Aggregate table/figure regeneration software and aggregate inputs|[Original release](https://github.com/jonghanko/rice-maize-gpp-conditional-pooling/releases/tag/v1.0.0)|

For1.1.0, download `rice-maize-gpp-conditional-pooling-v1.1.0.zip` from the release assets. It contains42files; use the accompanying `PACKAGE_MANIFEST.json` and `SHA256SUMS.txt`. Do not substitute the automatically generated source-code archive for the verification-data ZIP. [Scope, licences, source code and asset hashes](releases/v1.1.0/README.md) are recorded separately.

The1.1.0 build was committed before publication. Current access and immutability are established by the actual release page/API and asset digests; static preparation-time flags are not live status indicators.

Version1.1.0 supplies the selected stored-result verification projection, including daily keys, reference GPP, paired predictions, folds and reuse crosswalks. Full native archives, the complete predictor panel and saved estimators are not included. Prespecified, planned, secondary and post hoc comparison roles remain distinct. The study is conditional on the retained Korean rice and US maize data and does not establish general four-crop GPP/ET or agent value.
